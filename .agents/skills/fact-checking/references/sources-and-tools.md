# Источники и инструменты фактчека

## Правила работы с источниками

1. Всегда находи несколько источников для подтверждения.
   Пример: нашёл ссылку на товар на официальном сайте — посмотри ещё маркетплейсы.
2. Оценивай уровень авторитетности: статью на Дзене нельзя приравнять
   к энциклопедической статье.
3. Если источники можно ранжировать — доверяй авторитетным.
4. Если ранжировать нельзя и лучший источник определить нельзя — не ставь ошибку:
   возможно, профильное сообщество ещё не пришло к единому выводу.*
   *В пределах адекватности: статей про плоскую землю много, но научный консенсус
   о форме планеты есть.
5. Ссылку, данную моделью или автором текста, обязательно проверяй:
   не работает или ведёт не туда — это ошибка.
6. Пользуйся поиском по ключевому слову на странице первоисточника (Cmd+F / Ctrl+F).

## Работа с браузером

- Используй режим «Инкогнито», если выдача может быть смещена из-за персонализации поиска.
- Разводи рабочие и личные запросы по разным аккаунтам браузера: выдача будет «чище»,
  без перекоса в сторону личных предпочтений.

## Эталонные источники по конкретным темам

- Научные темы: журналы первого квартиля Q1 (https://journalinsights.com/quartile/q1);
  сложные научные статьи можно суммаризировать с помощью ИИ.
- Курсы валют, котировки акций, коэффициенты ставок: сайты центральных банков, бирж
  и брокеров (cbr.ru, moex.com), включая архивную информацию задним числом.
- Условия въезда/выезда (визовый режим, типы виз, сроки, документы, пошлины):
  официальные сайты посольств, консульств, министерств, уполномоченных визовых центров
  (mid.ru, ru.china-embassy.gov.cn).
- Событийная информация (место, дата, время мероприятия): крупные надёжные агрегаторы
  (Яндекс Афиша) и источники организаторов (официальные ресурсы учреждений, компаний, агентств).
- Юридические документы и точные цитаты: тексты оригиналов (Госуслуги, Консультант, Гарант);
  для организаций и мероприятий — уставные документы и официальные положения.

## Поисковые операторы

| Оператор | Назначение | Пример |
|----------|------------|--------|
| `site:` | Поиск по конкретному сайту (опровержение «на каком-то сайте написано») | `site:ru.wikipedia.org теория вероятностей` |
| `""` | Точные цитаты через кавычки | `"теория вероятностей"` |
| `( )` и `\|` | Граница слов и логическое ИЛИ | `купить nissan (Juke \| Qashqai)` |
| `+` | Фиксация обязательного слова в выдаче | `+обязательноеслово` |
| `-` | Исключение слова (полезно при омонимии) | `купить лук -растение` |
| `filetype:` | Файлы конкретного формата для массивов статистики | `цели устойчивого развития 2026 filetype:pdf` |
| `before:` / `after:` | Временной промежуток, дата в формате YYYY-MM-DD | `apple before:2007-06-29` |

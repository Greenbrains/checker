# Примеры разметки и крайние случаи

## Пример 1. Несколько ошибок в одном предложении
Текст: «Пушкин родился в Новосибирске в 1837 году».
Ошибки:
1. Место рождения: Пушкин родился в Москве, а не в Новосибирске.
2. Год рождения: 1799, а не 1837 (в 1837 году поэт погиб).
Источники: энциклопедические и биографические справочники.

## Пример 2. Сочинение о лирике Пушкина (находим только 2 ошибки)
Текст: «…В "Поэту" (1835) Пушкин призывает…; цитата: "Слушай себя и оценивай свой труд сам."»
Ошибки:
1. Датировка стихотворения «Поэту»: написано в 1830, а не в 1835 году.
2. Цитата искажена: в оригинале — «Ты сам свой суд; ты сам можешь строже оценить свой труд».
Не ошибки: оценочные суждения о красоте лирики и общие фразы о «вечных ценностях» — не проверяем.

## Пример 3. Это НЕ ошибки
Текст: «Ваш запрос очень интересный! Сахар может незначительно повыситься. 2 + 2 = больше 1.»
Вердикт: фактических ошибок нет (вводная фраза, упрощение в ненаучном тексте,
фактически верное утверждение; неполнота ответа — тоже не ошибка достоверности).

## Пример 4. Битая ссылка
Модель или автор дали ссылку на источник; ссылка не открывается или ведёт на другую страницу.
Вердикт: ошибка (ссылки проверяем обязательно).

## Чек-лист проверяемости тезиса

| Критерий | Проверяем | Не проверяем |
|----------|-----------|--------------|
| Есть конкретные числа/даты | ✓ | |
| Можно подтвердить источником/экспериментом | ✓ | |
| Мнение автора | | ✓ |
| Зависит от вкусовых предпочтений | | ✓ |

## Пример 5. Ошибка в расшифровке аббревиатуры
Текст: «Всероссийский центр ИССЛЕДОВАНИЯ общественного мнения (ВЦИОМ)».
Ошибка: официальное название — «Всероссийский центр ИЗУЧЕНИЯ общественного
мнения»; подменено одно слово. Тип: название.
Источник: wciom.ru (футер / раздел «О центре»), wikipedia.org.

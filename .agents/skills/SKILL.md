# Каталог навыков

| Название навыка | skill_name | Когда использовать |
| --- | --- | --- |
| Фактчек | fact-checking | Проверка текстов, скриншотов и таблиц на фактические ошибки: даты, цитаты, биографии, числа, официальные названия, направление динамики |
| Извлечение утверждений | fact-extract | Анализ материала и извлечение атомарных утверждений (claims) в JSON формате для последующей верификации |
| Веб-поиск | verify-web | Поиск релевантных URL и первоисточников для проверки утверждений, извлечение дословных цитат |
| Чтение источников | verify-read | Анализ текста из кэшированных источников и вынесение вердикта по утверждениям |
| Математическая проверка | verify-math | Проверка расчётов, сумм, разностей, вычисление возраста и дат через Python |
| Грамматическая проверка | verify-grammar | Проверка стилистики, орфографии, пунктуации и официальных названий |
| Арбитраж | fact-arbiter | Сведение вердиктов верификаторов в итоговый отчёт, разрешение расхождений, проверка внутренней противоречивости |
